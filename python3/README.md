Dreamfactory Scripting Examples for Python 3

NOTE: DreamFactory Python 3 scripting requires 'munch' package to be installed on server.

If working from a bitnami instance do the following in a terminal before using python 3 scripts:  
```sudo apt-get update```  
```sudo apt-get install python3-pip```  
```sudo pip3 install munch```

These scripts have been updated from Python 2.7 to Python 3 compatibility:
- Print statements converted from `print 'text'` to `print('text')`
- String encoding issues resolved
- Import statements added where needed
- All scripts tested for Python 3 compatibility

Python 3 syntax is now followed for all scripts in this directory.
